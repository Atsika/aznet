## What to expect

aznet carries an ordered byte stream through storage requests and polling. It encrypts application frames with Noise NN, which does not authenticate peer identity. Storage latency, credentials and resource cleanup remain part of your application's design.

Start with the local walkthrough. Before deployment, review [security](/core-concepts/security/), [delivery and cleanup](/reference/api/#closing-and-resource-ownership), and [upgrade requirements](/guides/validation/#upgrade-requirements).
